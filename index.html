المحاضرة: Network Traffic Analysis

من أول فتح Wireshark لحد أول Network Detective Challenge 🔎

صفحة عملية مصممة بحيث الطالب الصغير يقرأ الخطوة، ينفذها على جهازه، ثم يجيب سؤالًا بسيطًا. الهدف: فهم Packet + Protocol + Source + Destination، وليس حفظ برنامج كامل.

📦 Packet

جزء صغير من البيانات يتحرك في الشبكة.

📡 Protocol

قواعد وطريقة التواصل بين الأجهزة.

➡️ Source

المرسل.

🎯 Destination

المستقبل.

0قاعدة الأمان قبل البداية

🛡️ نحلل Traffic نملك حق تحليله فقط.
استخدم Wireshark على جهازك أو داخل Lab مصرح به. لا تحاول مراقبة أجهزة أشخاص آخرين أو شبكات لا تملك إذنًا بتحليلها.

1افتح Wireshark

  1. افتح برنامج Wireshark.
  2. ستظهر قائمة باسم Network Interfaces.
  3. لو جهازك متصل بالـWi‑Fi اختر Wi‑Fi.
  4. لو متصل بكابل اختر Ethernet.
💡 علامة مفيدة: الـInterface المستخدم عادة يظهر عليه حركة أرقام/Packets. اختَر الواجهة التي تستخدمها فعليًا.

2ابدأ Capture

  1. اضغط مرتين على Wi‑Fi أو Ethernet.
  2. انتظر عدة ثوانٍ.
  3. ستبدأ الصفوف بالظهور.
  4. بعدها اضغط زر Stop 🟥.

3افهم 3 أجزاء فقط من الشاشة

1️⃣ Packet List

قائمة بالـPackets التي التقطها Wireshark.

2️⃣ Packet Details

تفاصيل الـPacket التي اخترتها.

3️⃣ Packet Bytes

عرض منخفض المستوى للبيانات. مش مطلوب نفصله اليوم.

🎯 في محاضرة اليوم: لا تخاف من الشاشة. نحن نبحث فقط عن Protocol / Source / Destination.

4اعمل Traffic بسيط

بعد بدء Capture، نفّذ نشاطًا عاديًا على جهازك، مثل فتح موقع عام. ثم ارجع إلى Wireshark واضغط Stop.

⚠️ لا تدخل كلمات مرور أو بيانات خاصة أثناء التجربة. الهدف هو رؤية أنواع الاتصال، وليس البحث عن معلومات شخصية.

5أول Filter: DNS

في أعلى Wireshark ستجد خانة Display Filter.

اكتب بالضبط:

dns
  1. اضغط داخل Display Filter.
  2. اكتب dns.
  3. اضغط Enter.
  4. ستظهر Packets التي تطابق DNS.

6يعني إيه DNS؟

DNS يساعد الأجهزة على تحويل أسماء المواقع إلى عناوين IP يمكن للشبكة استخدامها.

👦 أنت

تقول: أريد موقعًا اسمه example.com.

📖 DNS

يساعد في العثور على عنوان IP المرتبط بالاسم.

🖥️ الاتصال

بعدها يمكن للجهاز التواصل مع العنوان المناسب.

7اقرأ Packet واحدة

  1. اضغط على Packet من القائمة.
  2. ابحث عن عمود Protocol.
  3. اقرأ Source.
  4. اقرأ Destination.
مثال: Source = 192.168.1.10 → Destination = 192.168.1.1 → Protocol = DNS

المعنى البسيط: جهاز أرسل Traffic إلى جهاز/خدمة أخرى، ونوع الاتصال الظاهر هنا DNS.

8جرّب TCP

امسح الفلتر السابق واكتب:

tcp

الفكرة المطلوبة اليوم: TCP أحد بروتوكولات نقل البيانات، ويهتم بالاتصال الموثوق بين الطرفين.

9جرّب UDP

اكتب في Display Filter:

udp

الفكرة المطلوبة اليوم: UDP بروتوكول نقل أبسط وأخف من TCP ولا يعمل بنفس طريقة TCP في ضمان التسليم.

🎯 مش مطلوب تحفظ كل تفاصيل TCP وUDP الآن. المطلوب تعرف إنهما Protocols مختلفة وتعرف كيف تبحث عنها في Wireshark.

📌 ملخص المحاضرة

إذا قدرت تقول الجمل التالية، فأنت نجحت:

  • Wireshark = Network Traffic Analyzer.
  • Packet = جزء من البيانات.
  • Protocol = قواعد/طريقة الاتصال.
  • Source = المرسل.
  • Destination = المستقبل.
